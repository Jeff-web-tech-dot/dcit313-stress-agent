# How we work in this repo

1. Never push straight to `main`.
2. Make a branch for your work: `git checkout -b yourname/short-task`.
3. Commit small and often, with a clear message ("add leave-one-subject-out split").
4. Open a Pull Request. **A different team member reviews it** before it is merged.
   We take turns being the reviewer so that everyone understands the code.
5. Never commit data files, `.pkl` files, passwords or keys.
6. Every number in the report must come from a script in `scripts/`.
