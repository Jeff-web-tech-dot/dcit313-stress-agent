# Data folder

The WESAD dataset is not uploaded to GitHub. Each member downloads it from the WESAD
dataset page and unzips it so the layout is:

```
data/WESAD/S2/S2.pkl
data/WESAD/S3/S3.pkl
...
data/WESAD/S17/S17.pkl
```

Subjects are S2 to S17 without S12 (15 people). S1 and S12 were discarded by the
dataset authors because of sensor malfunction.

Record the page URL and download date in docs/datasheet.md.
